Why smaller

Not a harder
minifier.

The JFB gap is not Vite property-mangling Solid harder. Solid 2.0 already shortens internal keys at publish time. LilScript wins because it lowers a typed, closed client: owned fields become slots, host names stay exact, and the unused Solid 2.0 graph never exists.

Owned fields become slots

Solid’s reactive graph is objects. A signal/owner carries many named fields — even after ^_ mangling they stay e.se, e.Ne. LilScript structs lower to numeric slots (e[0], e[1]). extern class members like textContent stay. Terser cannot prove that.

Same templates, thinner For

Both apps compile the jumbotron to cloneNode HTML templates. Solid JSX does that in @solidjs/web. LSX does it in the lilx lowerer, then keyedEach reconciles rows. The UI spelling matches; the list runtime does not carry Solid’s hydration/async owner graph.

Client-only graph

Solid 2.0’s published client still contains the signals scheduler, transitions, optimistic hooks, and a large hydration module. A Vite app tree-shakes some of it. We never compiled SSR, hydration, or the unused @solidjs/signals subsystems into this port.

Two ways we ship

The JFB / lab LSX apps are closed-world: one LilScript graph, unused functions deleted, exports mangled. npm install @itslil/solidjs is the reusable ESM — larger than a demo, still the one vendor chunk a JS app pays. Do not add the 18 demo rows; that counts Solid 18 times.

Tooling

LilScript, LSX, this page

  1. LilScript is the language and compiler. It types the program, then searches JS spellings against Brotli. Owned aggregates can be positional. That compiler lives in yeargun/lilscript — see why it beats minifying harder and mangle / ABI.
  2. LSX (.lilx) is JSX for LilScript. parse-jsx.mjs reads the markup; lower.mjs emits cloneTemplate plus For / Show calls into lsx.lil. Same idea as Solid’s JSX → template().cloneNode(true).
  3. This lab pairs each Solid 2.0 Vite app with the LSX compile of the same UI. The hero and the first evidence row are official JFB (one vendor chunk). The grid is closed-world extras: filters, side-by-side iframes, replay. CPU cards are the krausest harness, not inferred from size.
