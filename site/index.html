and Brotli.

Gate metrics are gzip-9 and Brotli-11 on matching browser artifacts, plus uncompressed raw. Values are generated by npm run build:apps. The js-framework-benchmark keyed table is the fair app-sized comparison.

Case Solid raw Lil raw Solid gzip Lil gzip Solid brotli Lil brotli Brotli Δ

Important distinction. Demo sizes are closed-world application builds, where LilScript can delete unused runtime. Solid 2.0’s npm browser entry is already concatenated (dist/solid.js + dist/web.js), so a counter still carries most of the client. The fairer app-sized number is the js-framework-benchmark keyed table: both are the same jumbotron app, Solid’s JSX compiled by the Solid plugin and solidlil’s LSX compiled by LilScript, then terser. 33,701 B vs 10,020 B JS raw (11,420 B vs 3,609 B Brotli-11). The reusable package ESM is a separate artifact from npm run test:size. Performance is measured on that same JFB harness, not inferred from size.
